# CRICVISION

Cricket Match Win Prediction Using Machine Learning

## Project Description

CRICVISION predicts the winning probability of a cricket team
using machine learning algorithms.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Models

- Logistic Regression
- KNN
- Decision Tree
- Random Forest

## Dataset

The dataset contains cricket match information such as:

- Runs Left
- Balls Left
- Wickets Left
- Total Runs
- CRR
- RRR
- Result

## How to Run

Open the `.ipynb` file in Google Colab and run the cells.
